Speaker palette (dot / ink): blue `#3382D6` / `#2A6CB5`, purple `#B854A3` / `#9A3F87`, green `#299975` / `#1E7B5D`,
amber `#D18524` / `#8F5A12`. Speakers cycle through the four in order of first speech.

Radii: 14 (rows, small cards) · 16 (cards) · 20 (large cards) · 24 (hero card). Type: **SF Pro Rounded** bold for
headlines and titles (`Tokens.Font.rounded`), **SF Pro** for body text. Numbers that change (timers, times,
percentages) use tabular figures.

Dark mode: the canvas defines a light palette only (the Dictating screen is dark by design). A dark palette is an
M8 design task for the owner; until it exists, do not invent one in code.

## Structure

**Transforms** (`sparkles`), **Settings** (`gearshape`). Transcript is pushed from Capture's Recent list and from
Library.

## Components (`ChirpUI`)

`Card`, `SeedOfLifeCover`, `RosetteMark`, `ParakeetMark` (the canvas's SVG path as a SwiftUI `Shape`),
`StatusChip`, `SpeakerDot`. Shared app views: `NotBuiltYetSheet(title:milestone:summary:)`, `PlayerBar`,
`AboutSection`, and (M1.5) `AudioTrackPickerSheet`, "Choose an audio track" for a multi-track file, presented from
`RootTabView` whenever `TranscriptionJobCenter.pendingAudioTrackSelection` is set; it cannot be swiped away, so the
person either picks a track or taps Cancel import.

## Rules

- **Honest UI.** Progress comes only from real work (pipeline stages and engine callbacks). No timers that fake
  progress, no demo rows, no buttons that pretend. Unbuilt surfaces open `NotBuiltYetSheet` naming the milestone.
- **Errors are actionable.** A failed row shows the error in red with Retry; a missing model shows a banner with a
  button to Settings.
- **Copy corrections to the canvas** (binding):
  - "Hold the Action Button" → **"Press the Action Button"**. Third-party apps get no key-up event from the Action
    Button, so hold-to-talk is impossible.
  - The meeting **"Room"** meter has no iOS source: iPhone apps cannot capture other apps' or system audio. **M3
    decision: dropped.** Parakeet records one built-in-mic stream without voice processing, so a second meter would
    repeat the "Mic" level; if a later milestone enables voice isolation, a raw-vs-isolated pair can be measured
    on the device then (plan 012 Step 7). "Mic + room audio" reads "Microphone · saving on this iPhone".
  - Canvas numbers are illustrative: show real model sizes on disk, not "620 MB"; show the language the engine
    actually supports ("Automatic (25 languages)" for v3), not "English (US)"; clean-up is Raw/Clean, not
    "Balanced".
  - The canvas's illustrative values for unbuilt settings and Transforms read as real state to a user who hasn't
    built them yet (final-review Lane C 6). Settings → Capture's placeholder rows show **"Not built yet"**, not the
    canvas's specific "Action Button" / "Double tap" / "Tap to stop" sample values. The Transforms list's "Brief"
    row reads **"A custom Transform template · BLUF, then three bullets"**, not "Your custom Transform …" — nothing
    is the user's yet.
- **Build identity is visible**: Settings → About shows version (build), commit, branch, date and a copy button.
- **Accessibility**: every icon-only control has a label; tap targets are at least 44 pt; text uses Dynamic Type
  styles scaled from the canvas sizes. A full accessibility pass is M8.
- **iPhone portrait first.** The target is universal (iPhone and iPad); the iPad layout is M8.
