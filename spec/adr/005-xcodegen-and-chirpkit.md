# ADR-005: XcodeGen Project plus the ChirpKit Local Package

> Status: Accepted
> Date: 2026-09-22
> Related: [spec/03-architecture.md](../03-architecture.md), [ADR-004](004-engine-plugin-architecture.md),
> [iOS platform research §2](../../docs/research/2026-09-22-ios-platform-constraints.md)

## Context

The Gemini port built the iPhone app as a SwiftPM `executableTarget` and assembled the `.app` by hand. SwiftPM cannot
produce app extensions (share, keyboard, widget, Live Activity), entitlements or a real Info.plist, so the extensions
it described could not exist. A hand-maintained `.pbxproj` is the worst format for coding agents: dense, full of
generated IDs, and conflict-prone.

XcodeGen generates the project from a readable YAML spec and supports app extensions, local packages, build scripts,
Info.plist and entitlements generation. Xcode 27.2 (beta) introduces an agent-editable JSON project format that
XcodeGen cannot produce yet.

## Decision

- `project.yml` (XcodeGen) is the **only project source of truth**. `iChirp.xcodeproj` is generated by
  `scripts/gen.sh`, gitignored, and never edited by hand.
- Targets: `iChirp` (app: composition root plus screens), `iChirpTests` (app-hosted tests). Extensions are added as
  XcodeGen targets in their milestones (share: M1.5; widget/Live Activity: M2; keyboard: M8).
- Build settings live in `Config/*.xcconfig`; local signing in the gitignored `Config/Signing.local.xcconfig`.
- All logic lives in the local Swift package **`ChirpKit`** (`ChirpKit/Package.swift`), one target per module, with
  tests that run on the Mac host via `swift test`.
- A post-build script stamps the build identity into the built Info.plist ([ADR-008](008-distribution-and-build-identity.md)).
- Lint (`swift format lint --strict`) is a hard gate from day one.

## Alternatives considered

- **Hand-maintained `.xcodeproj`.** Rejected: unreadable diffs and merge conflicts for agents.
- **Tuist.** Rejected for now: more machinery (caching, registry, cloud) than one app needs.
- **Pure SwiftPM app.** Rejected: cannot carry extensions or entitlements.
- **Xcode 27.2 JSON project format.** Reconsider once it leaves beta and the Mac runs a supported macOS.

## Consequences

- New app files require `scripts/gen.sh` (scripts run it for you).
- Package tests are fast and need no simulator; the package must stay platform-neutral (iOS-only APIs stay in the
  app target or behind protocols).
- Build scripts that write outside declared outputs need `ENABLE_USER_SCRIPT_SANDBOXING = NO` or declared
  inputs/outputs.
