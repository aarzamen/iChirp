## Why this matters

"Highly polished" is part of the end goal. This milestone finishes the surfaces that make Parakeet feel native:
proper document exports, dictation from any text field, Transforms from the Share sheet, widgets, full
accessibility, and a real iPad layout.

## Scope

- **In scope (one lane each):**
  > Items 1 and 2 were built by plan 022 Step 6 (`ChirpExport/PDFDocumentRenderer.swift`,
  > `DOCXDocumentWriter.swift`; Core Text and an own OOXML writer, no third-party library); the rest is still open.
  1. **PDF export:** multi-page, paginated text via `UIMarkupTextPrintFormatter` + `UIPrintPageRenderer` (or
     `UIGraphicsPDFRenderer` with Core Text), with title, speakers and timestamps; never a single truncated page.
  2. **DOCX export:** a real OOXML writer (or `shinjukunian/DocX`, MIT, after a license check); never plain text in a
     `.docx`.
  3. **Keyboard extension:** no microphone access in keyboards (Apple rule). The keyboard opens the app with a SwiftUI
     `Link` to `ichirp://dictate`, the app records with its Live Activity, the user returns via the status-bar back
     link, and the text arrives through the App Group (needs Full Access). Loads no models (about 48–60 MB budget).
  4. **Transforms extension:** an Action extension that returns rewritten text where the host accepts it; otherwise
     copies it. Verify "Replaces your selection" per host and word the UI honestly.
  5. **Widgets and Controls:** recent transcripts widget (needs App Group data; test the SideStore App Group widget
     bug), Controls for Record Meeting.
  6. **Accessibility:** VoiceOver labels and actions everywhere, Dynamic Type at every size, 44 pt targets, contrast,
     Reduce Motion.
  7. **iPad layout:** `NavigationSplitView` for Library → Transcript; multitasking sizes.
  8. **Localization:** String Catalog; English complete; other languages only on the owner's request.
  9. **Dark palette and Library grid:** only from an owner-approved design update to the canvas.
- **Must not change:** extension budget (app + at most two extensions for SideStore, per ADR-008, unless the owner
  approves more); no models in extensions; privacy rules; existing exports' output.
- **Out of scope:** App Store submission (no distribution certificate; GPL permission needed).

## Steps

For each lane: (1) confirm prerequisites and any account change needed (App Groups, new extension App IDs) with the
owner; (2) implement with tests for the logic (export renderers are pure and testable on the Mac host); (3) verify on

**Export verification:** render a synthetic 2-hour transcript to PDF and DOCX; open both in Files and Pages/Word;
check pagination, speakers and timestamps.

**Keyboard verification (device):** dictate into Messages via the keyboard round-trip; confirm no crash from memory.
