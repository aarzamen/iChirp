# iChirp M0 + M1 Implementation Plan (foundation + Parakeet file transcription)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restructure the repo into an agent-ready iChirp workspace. Build the iOS app shell from the design canvas, and ship real FluidAudio Parakeet v3 file transcription (import → normalize → transcribe → diarize → persist → Library/Transcript → export), verified on the owner's iPhone 17 Pro.

**Architecture:**
- An XcodeGen project (`project.yml`) with an iOS app target that is only a composition root plus screens.
- All logic lives in the local SwiftPM package `ChirpKit`: Core, Audio, Text, Store, Export, EngineFluidAudio, Features and UI.
- Engines are plug-in targets behind ChirpCore protocols. The transcription pipeline is a port of MacParakeet's `TranscriptionService` file path, with FFmpeg replaced by AVFoundation.

**Tech Stack:** Swift 6.2 (strict concurrency), SwiftUI, iOS 26, Xcode 26.6, XcodeGen 2.45.4, FluidAudio **exact 0.16.1**, GRDB 7, XCTest.

**Spec:** `docs/plans/2026-09-22-002-feat-ichirp-foundation-design.md` (approved). Design handoff: `docs/plans/2026-09-22-001-feat-iphone-app-design-handoff.md`. MacParakeet pipeline map: `docs/research/2026-09-22-macparakeet-pipeline-map.md`.

## Global Constraints

- **Toolchain:** minimum iOS **26.0**; package platforms `.iOS(.v26), .macOS(.v26)`; `swift-tools-version: 6.2`; Swift 6 language mode everywhere.
- **Dependencies:**
  - FluidAudio: `.package(url: "https://github.com/FluidInference/FluidAudio", exact: "0.16.1")`.
  - GRDB: `.package(url: "https://github.com/groue/GRDB.swift", from: "7.0.0")`.
  - No other third-party dependencies in M1.
- **Identity:** display name **Parakeet**; bundle id `com.aarzamen.ichirp`; codename, repo, Xcode project, targets and package all use **iChirp / ChirpKit**.
- **Upstream reference:** `upstream/macparakeet/` equals upstream commit `bbae9e0e` byte for byte and is **never edited**.
- **Porting provenance:** every ported file starts with `// Ported from MacParakeet (GPL-3.0): <path relative to upstream/macparakeet> @ bbae9e0e` plus a one-line summary of the changes.
- **Honest UI:** no simulated progress. An unbuilt feature shows "Not built yet — milestone Mx".
- **Privacy:** audio and transcripts never leave the device in M1. No network calls except FluidAudio model downloads from Hugging Face.
- **Fixtures:** synthetic only (macOS `say`). No real recordings and no PHI in the repo.
- **Commits:** on branch `ichirp/foundation`, local only, **never push**. Following the repo rule, **no assistant `Co-authored-by` trailers**. Commit messages describe state.
- **Tests:** iterate with `scripts/check.sh <Filter>`; run the full package suite once at the end.
- **Lint:** `swift-format lint --strict` must be clean for `App/` and `ChirpKit/`.

- [ ] **Step 5: `scripts/stamp_build_identity.sh`.** It runs inside Xcode's build and edits the *built* Info.plist, never the source file.

```bash
#!/usr/bin/env bash
# Writes git commit/branch/dirty + UTC build date + monotonic CFBundleVersion into the built app's Info.plist.
set -euo pipefail
PLIST="${TARGET_BUILD_DIR}/${INFOPLIST_PATH}"
cd "${SRCROOT}"
COMMIT=$(git rev-parse --short=12 HEAD 2>/dev/null || echo unknown)
BRANCH=$(git rev-parse --abbrev-ref HEAD 2>/dev/null || echo unknown)
DIRTY=$([ -n "$(git status --porcelain --untracked-files=no 2>/dev/null)" ] && echo 1 || echo 0)
DATE=$(date -u +%Y-%m-%dT%H:%M:%SZ)
BUILD=$(date -u +%Y%m%d%H%M)
for kv in "ChirpGitCommit:$COMMIT" "ChirpGitBranch:$BRANCH" "ChirpGitDirty:$DIRTY" "ChirpBuildDateUTC:$DATE" "CFBundleVersion:$BUILD"; do
  /usr/libexec/PlistBuddy -c "Set :${kv%%:*} ${kv#*:}" "$PLIST"
done
echo "Stamped $COMMIT ($BRANCH, dirty=$DIRTY) build $BUILD"
```

@testable import ChirpCore

final class SpeechJobSchedulerTests: XCTestCase {
    actor Log { var items: [String] = []; func add(_ s: String) { items.append(s) } }

    func testBackgroundJobsRunByPriorityThenFIFO() async throws {
        let scheduler = SpeechJobScheduler()
        let log = Log()
        let gate = AsyncStream<Void>.makeStream()
        // Occupy the background slot so the next three queue up.
        let blocker = Task { try await scheduler.run(.fileTranscription) { for await _ in gate.stream { break }; await log.add("blocker") } }
        try await Task.sleep(for: .milliseconds(50))
        let f2 = Task { try await scheduler.run(.fileTranscription) { await log.add("file2") } }
        try await Task.sleep(for: .milliseconds(20))
        let live = Task { try await scheduler.run(.meetingLiveChunk) { await log.add("live") } }
        try await Task.sleep(for: .milliseconds(20))
        let fin = Task { try await scheduler.run(.meetingFinalize) { await log.add("finalize") } }
        try await Task.sleep(for: .milliseconds(20))
        gate.continuation.yield(())
        _ = try await (blocker.value, f2.value, live.value, fin.value)
        let order = await log.items
        XCTAssertEqual(order, ["blocker", "finalize", "live", "file2"])
    }

    func testDictationUsesInteractiveSlotAndIsNotBlockedByBackground() async throws {
        let scheduler = SpeechJobScheduler()
        let gate = AsyncStream<Void>.makeStream()

        try await Task.sleep(for: .milliseconds(50))
        let result = try await scheduler.run(.dictation) { "dictated" }
        XCTAssertEqual(result, "dictated")
        gate.continuation.yield(()); _ = try await background.value
    }

    func testCancellingPendingJobRemovesIt() async throws {
        let scheduler = SpeechJobScheduler()
